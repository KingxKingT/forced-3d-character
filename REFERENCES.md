# Implementation references

The generator targets Blender's Python API. Consult the documentation for the exact Blender version installed locally, since operator parameters can change between versions.

- [Blender Python API 4.5 — `bpy.ops.wm.obj_export`](https://docs.blender.org/api/4.5/bpy.ops.wm.html)
- [Blender Python API — glTF 2.0 exporter](https://docs.blender.org/api/3.0/bpy.ops.export_scene.html)
- [glTF 2.0 specification](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html)

The docs above describe relevant interfaces and format behavior; they do not imply the full project was executed against every Blender version.
