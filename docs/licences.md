# Reusable Open-Source Code and Asset Routes

No third-party code, character base, or asset pack is bundled in this improved repository. The table identifies reuse boundaries, not an instruction to download everything. Check the exact version again before redistribution; code, base meshes, targets, textures, and generated output can have different licences.

## Practical policy

Prefer original procedural code and clearly CC0 assets for the optional quality path. Keep a provenance file with source URL, version/commit, download date, licence text, and modifications. “Open source,” “free download,” and “free output” are not interchangeable. Never relicense third-party code or assets merely by placing them in this MIT repository.
